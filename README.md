# 📘 Exercícios de HTML5 e CSS3  

Este repositório reúne os exercícios desenvolvidos durante o curso de **HTML5 e CSS3** do [Curso em Vídeo](https://www.cursoemvideo.com).  

## 🎯 Objetivo  
Praticar e consolidar os conceitos fundamentais de **HTML5** e **CSS3**, aplicando na prática os conteúdos vistos nas aulas.  

## 📂 Conteúdo  
- Estrutura básica de páginas HTML  
- Formatação de textos e listas  
- Links e navegação  
- Imagens e multimídia  
- Tabelas e formulários  
- Estilização com CSS (cores, fontes, layouts)  
- Box model e posicionamento  
- Responsividade e boas práticas
